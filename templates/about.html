ABOUT THE PROJECT

Built around support.

NVIDIA Support is a Discord support bot project focused on giving community members a clear way to ask for help through private tickets.

OUR PURPOSE
N.

Make asking for help simple.

The current bot creates private ticket channels, lets the ticket owner or authorized staff close them, and gives administrators a panel command to publish the entry point.

01 / CORE FEATURE

Ticket management

Private channels are created for a member and the configured support role.

02 / ADMIN TOOL

Ticket panel

The /ticketpanel command is restricted to administrators in the supplied source.

03 / PROJECT CREDIT
